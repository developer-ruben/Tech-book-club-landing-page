# Tech Book Club Landing Page

A responsive landing page for a fictional tech reading community. This project was built as a Frontend Mentor challenge to practice semantic HTML, modern CSS layout, and polished UI styling.

## Overview

The page promotes a monthly membership for developers who want to read curated technical books, join community discussions, and attend virtual meetups. It includes a bold hero section, feature highlights, a reading journey flow, and membership pricing cards.

## Features

- Responsive layout optimized for desktop and mobile screens
- Strong editorial-style hero section with clear call-to-action
- Benefit-driven content blocks highlighting the club experience
- Membership options with a featured pricing card
- Hover and focus states for interactive elements
- Clean, reusable CSS variables and component styling

## Tech Stack

- HTML5
- CSS3
- Custom fonts and local assets
- Responsive design with Flexbox and layout utilities

## Project Structure

- `index.html` — page structure and content
- `style.css` — site styling, layout, colors, and responsiveness
- `assets/` — images, icons, and local font files
- `design/` — design references and preview assets

## Run Locally

1. Clone or download the project.
2. Open `index.html` directly in your browser, or serve the folder locally with a simple static server.
3. For example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Design Notes

This implementation focuses on matching the provided design closely while keeping the code maintainable and easy to follow. The styling uses CSS custom properties for a consistent color palette, spacing scale, and typography system.
